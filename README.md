# AI 信号台

AI 工具导航 + 实时状态信号：额度重置、模型发布、榜单价格、热点资讯。

- 纯静态单文件（`index.html`），零外部依赖，可离线打开
- 精选 119 个站点，14 个分类；所有链接经连通性核验
- 支持搜索（按 `/` 聚焦）、分类筛选、一键复制链接
- 支持深色模式（跟随系统）

## 本地预览

直接双击 `index.html`，或：

```bash
python3 -m http.server 8080
```

## 部署

推送到任意静态托管即可（GitHub Pages / Cloudflare Pages / Vercel / Netlify）。

## 数据维护

站点数据在 `index.html` 内的 `SITES` 数组，字段：

| 字段 | 说明 |
|---|---|
| `n` | 名称 |
| `u` | 链接 |
| `d` | 一句话说明 |
| `c` | 分类 id（见 `CATS`） |
| `hot` | 可选，标记热门 |

新增分类只需在 `CATS` 里加一行。
